# FPP Audio Streaming v0.4 – cPanel package

This archive contains the original v0.3 FPP plugin and a new **cPanel Passenger-compatible backend** in `backend/cpanel_app.py`.

**Read `backend/CPANEL-SETUP.md` first.** The old standalone `backend/server.py` remains for the original VPS mode, but must not be used for cPanel.

The FPP agent and plugin configuration remain unchanged from v0.3. Only the backend deployment is adapted. No hardware testing or live hosting deployment has been performed.
